# Application Icons

This folder contains the application icons for different platforms:

- `icon.svg` - Source SVG icon (512x512)
- `icon.png` - PNG icon for Linux (512x512)
- `icon.ico` - ICO icon for Windows (multiple sizes)
- `icon.icns` - ICNS icon for macOS (multiple sizes)

## Generating Icons

To generate platform-specific icons from the SVG source, you can use tools like:

1. **electron-icon-maker**: `npm install -g electron-icon-maker`
2. **Online converters**: Convert SVG to ICO, ICNS formats
3. **ImageMagick**: Command line tool for image conversion
